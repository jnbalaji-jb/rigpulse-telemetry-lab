# Example data

Use `rigpulse generate --out demo_data --rigs 4 --hours 240 --seed 42` to create reproducible labeled synthetic readings. The labels are written to a separate truth file, never used for anomaly scoring.

`example_telemetry.csv` and `example_ground_truth.csv` are intentionally small, synthetic fixtures provided solely for quick local experimentation. They are not live rig data.
